# Changelog

## 3.0.0

- Add Gradient, Rainbow, Chrome, Copper, Beveled, Double Line, Triple Line, Pearls, Marquee and Candy Stripe frames.
- Add solid, dashed, dotted and dash-dot line patterns, adjustable pattern spacing, a second frame color and gradient direction.
- Add Sunset, Ice Chrome, Pearl, Candy and Dashed Gold presets.
- Add multiline labels, left/center/right alignment, line spacing, underline, strikethrough and adjustable text outline color/width.
- Add Gradient, Double Outline, Emboss and Engraved text effects.
- Keep frames aligned to actual image transparency across widths and styles.
- Include author attribution in About and Windows executable properties, an MIT license, build instructions and synthetic regression tests.

## Earlier development

- Asset catalogue with grouped quality variants, readable names, search and clickable menu previews.
- Picture crop, masks, symbol overlays, whole-font styling, restore and export.
- Layer order, deletion/restoration and opacity controls.
- Transactional backups and independent Texture Loader pack generation.
