# Personal Media Hub on Render

Private-install Stremio / Nuvio addon. This isolated deployment branch does not affect the default branch. Streams are examples from third-party public sources; confirm the rights and current availability before relying on them. The anime catalog is empty until you add authorized links. Hanime is only an external link on the configuration page, not an embedded stream. The access key must remain in Render environment variables and not this repository.

Runtime Node.js 20+. Start: `npm start`. Health: `/health`.
